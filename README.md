# 音乐播放器 Pro

一个功能完整、界面精致的现代化音乐播放器，基于 JavaFX 和 VLCJ 开发。

## 功能特性

### 🎵 播放功能
- ✅ 本地音乐文件播放（MP3、WAV、FLAC、APE、OGG 等多种格式）
- ✅ 在线音乐 URL 播放（HTTP/HTTPS 直链、网络电台流）
- ✅ 播放/暂停/停止/上一曲/下一曲控制
- ✅ 拖动进度条快速定位
- ✅ 音量调节

### 📋 列表管理
- ✅ 添加本地音乐文件/文件夹
- ✅ 添加在线音乐 URL
- ✅ 播放列表快速管理（右键删除/清空）
- ✅ 双击播放列表中的歌曲
- ✅ 列表自动滚动到当前播放歌曲

### 🎚️ 播放模式
- ✅ 单曲循环模式
- ✅ 列表循环模式
- ✅ 不循环模式
- ✅ 随机播放模式

### 🎨 用户界面
- ✅ 现代化深色主题设计
- ✅ 流畅的动画和过渡效果
- ✅ 实时播放进度显示
- ✅ 当前歌曲信息展示
- ✅ 缓冲进度条
- ✅ 播放列表详细信息

### 🛠️ 技术特点
- ✅ 基于 VLCJ 调用本地 VLC（D:\\Program Files\\VideoLAN\\VLC）
- ✅ 完全的异步播放引擎
- ✅ 线程安全的 UI 更新
- ✅ 完善的错误处理机制
- ✅ 详细的日志输出

## 系统要求

- **Java**: JDK 18 或更高版本
- **VLC**: 3.0 或更高版本（安装在 D:\\Program Files\\VideoLAN\\VLC）
- **OS**: Windows 7 及以上

## 安装步骤

### 1. 安装 JDK 18
```bash
# 下载并安装 JDK 18
# https://www.oracle.com/java/technologies/downloads/
```

### 2. 安装 VLC
```bash
# 下载并安装 VLC
# https://www.videolan.org/vlc/
# 确保安装路径为: D:\Program Files\VideoLAN\VLC
```

### 3. 编译项目
```bash
mvn clean package
```

### 4. 运行应用
```bash
# 方式一：使用 Maven
mvn javafx:run

# 方式二：直接运行 JAR
java -jar target/music-player-2.0.0-shaded.jar
```

## 使用指南

### 添加音乐
1. **添加文件**: 点击「📁 添加文件」按钮，选择一个或多个音乐文件
2. **添加文件夹**: 点击「📂 添加文件夹」按钮，选择包含音乐的文件夹
3. **添加网址**: 点击「🌐 添加网址」按钮，输入 HTTP/HTTPS 音乐直链

### 播放控制
- **播放/暂停**: 点击「▶」或「⏸」按钮
- **上一曲**: 点击「⏮」按钮
- **下一曲**: 点击「⏭」按钮
- **停止**: 点击「⏹」按钮

### 播放模式
- **🔀 随机**: 点击随机按钮启用随机播放
- **重复模式**: 选择「不循环」、「单曲循环」或「列表循环」

### 音量控制
- 拖动右下角的音量滑块调节音量（0-100%）

### 列表管理
- **双击歌曲**: 立即播放该歌曲
- **右键菜单**: 删除单曲或清空列表

## 常见问题

### Q: 无法找到 VLC？
A: 确保 VLC 安装在 `D:\Program Files\VideoLAN\VLC`，或设置环境变量 `vlc.path`

### Q: 播放在线音乐失败？
A: 确保 URL 是直接可访问的音频链接（如 .mp3 文件或网络电台流）

### Q: 应用启动缓慢？
A: 首次启动会加载 VLC 库，属正常现象

### Q: 如何修改 VLC 路径？
A: 在启动时设置 JVM 参数：
```bash
java -Dvlc.path="C:\\VLC" -jar music-player-2.0.0-shaded.jar
```
